# Themes

A theme sets the default look of every chart in the app: the color palette, the paints and sizes of series and axes,
the tooltip and legend, and the hover effects. The theme only fills the properties you did not set: a property set in
code or XAML keeps its value, the theme never replaces it. When no theme is registered, LiveCharts adds the default
theme, which follows the light or dark mode of the app.

:::info
Every member is listed in the API explorer:
[Theme]({{ website_url }}/api/{{ version }}/LiveChartsCore.Themes.Theme),
[ThemesExtensions]({{ website_url }}/api/{{ version }}/LiveChartsCore.SkiaSharpView.ThemesExtensions) (the default
theme) and
[LiveChartsthemeExtensions]({{ website_url }}/api/{{ version }}/LiveChartsCore.Themes.LiveChartsthemeExtensions)
(the theme rules).
:::

## Light and dark

The default theme has a light and a dark variant. The dark one uses a lighter palette, a black background and light
text:

![image](https://raw.githubusercontent.com/beto-rodriguez/LiveCharts2/master/docs/_assets/light-and-dark-charts.gif)

Where the UI framework reports the theme of the app, the chart follows it and switches when it changes:

- Avalonia: the `ActualThemeVariant` of the application.
- WinUI and Uno: the `ActualTheme` of the chart control, so a `RequestedTheme` set on the app or on a parent element
  applies to the chart.
- MAUI: the `RequestedTheme` of the application, which is the `UserAppTheme` when the app sets one, or the theme of the
  system.
- WPF, WinForms, Blazor and Eto: these frameworks do not report a theme, the chart is always light unless you force
  the dark variant.

## Force light or dark

When the UI framework reports a theme, the recommended way to get a dark chart is to set the theme of the app, so the
charts match the rest of the UI. Otherwise, register the variant you want when the app starts:

```csharp
LiveCharts.Configure(config => config
    .AddDarkTheme()); // or .AddLightTheme() // mark
```

`AddDarkTheme()` and `AddLightTheme()` are shortcuts for
`AddDefaultTheme(requestedTheme: LvcThemeKind.Dark)` and `AddDefaultTheme(requestedTheme: LvcThemeKind.Light)`.
`LvcThemeKind.Unknown`, the default, follows the app.

## Customize the default theme

`AddDefaultTheme`, `AddDarkTheme` and `AddLightTheme` take a function that adds your own rules to the default
theme. Your rules run after the default ones, so they override them. This sample changes the palette, the
animations, the corner radius of the bars and the separators of the axes:

```csharp
{{~ render "~/../samples/ViewModelsSamples/LiveChartsThemeExtensions.cs" ~}}
```

Then register it when the app starts:

```csharp
LiveCharts.Configure(config => config.AddMyCustomTheme());
```

The theme API:

- `OnInitialized` runs the first time a chart uses the theme, and again every time the app switches between light
  and dark. Set the values that are not rules there, such as `theme.Colors`, the palette.
- `HasRuleForAxes`, `HasRuleForAnySeries` and one rule per series type (`HasRuleForLineSeries`,
  `HasRuleForBarSeries`, `HasRuleForPieSeries`, `HasRuleForTreemapSeries` and so on) run for each axis or series when a
  chart draws it the first time, and again when the app switches between light and dark.
  `HasPostRuleForAnySeries` runs after the rules of the series type, when the series already has its paints.
- `HasRuleForChart` styles the chart control itself, see the next section.
- `theme.IsDark` tells a rule which variant is active.

Each series takes the color of the palette at its position in the chart's series collection; when there are more
series than colors, the palette starts again. `ColorPalletes` has some palettes ready to use:

- `ColorPalletes.Default` is the palette of the default theme, the same in light and dark, so a series keeps its color
  when the app switches. It has vivid Material Design colors, light and dark ones mixed: colorblind readers tell
  colors apart mostly by how light they are, and the order keeps every pair of the first six colors apart with
  red-green color blindness.
- `ColorPalletes.MaterialDesign500`, `MaterialDesign200` and `MaterialDesign800` are Material Design palettes; the
  default theme used the first two, in light and dark, before version 3.0.
- `ColorPalletes.FluentDesign` follows the Fluent Design colors.

Color should not be the only way to tell series apart: the legend, the tooltip and data labels name them too.

The source code of the default theme is a complete example of every rule:
[ThemesExtensions.cs](https://github.com/beto-rodriguez/LiveCharts2/blob/master/src/skiasharp/LiveChartsCore.SkiaSharp/ThemesExtensions.cs).

## Chart properties

Besides series and axes, a theme can set the properties of the chart control (the `IChartView`), for example the
legend and tooltip paints and sizes, the animations speed or the draw margin. Use `HasRuleForChart`; the rule runs on
every platform, so you do not need a XAML style per platform.

```csharp
LiveCharts.Configure(config => config
    .AddDefaultTheme(theme => theme
        .HasRuleForChart(chart =>
        {
            chart.LegendTextSize = 14;
            chart.TooltipTextSize = 14;
            chart.AnimationsSpeed = TimeSpan.FromMilliseconds(500);
        })));
```

As with series and axes, a value you set on the chart in code or XAML, or bind, wins over the rule.

## Your own theme

`HasTheme` registers a theme built from scratch, with none of the default rules. Such a theme must define the
default tooltip and legend and a palette. Anything else it does not set keeps the default value of the property: for
example, an axis with no `LabelsPaint` draws no labels.

```csharp
LiveCharts.Configure(config => config
    .HasTheme(theme => theme // mark
        .HasDefaultTooltip(() => new SKDefaultTooltip()) // mark
        .HasDefaultLegend(() => new SKDefaultLegend()) // mark
        .OnInitialized(() => theme.Colors = ColorPalletes.FluentDesign) // mark
        .HasRuleForLineSeries(series =>
        {
            // configure the line series here...
        })));
```

The theme registered in `LiveCharts.Configure` applies to every chart. To give one chart a different theme, set its
`ChartTheme` property.
