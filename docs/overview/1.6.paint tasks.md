# Paints

A paint defines how LiveCharts draws a shape: its color or gradient, the thickness and dash pattern of a stroke, a
shadow, and the font of a text. Every property of a series, axis or chart that draws something takes a paint, such as
`Fill`, `Stroke`, `GeometryFill`, `DataLabelsPaint`, `LabelsPaint`, `SeparatorsPaint` or `TooltipTextPaint`.
LiveCharts draws with [SkiaSharp](https://github.com/mono/SkiaSharp) and its paints wrap a SkiaSharp `SKPaint`, so
colors, points and fonts use the SkiaSharp types (`SKColor`, `SKPoint`, `SKTypeface`). There are three paints,
`SolidColorPaint`, `LinearGradientPaint` and `RadialGradientPaint`, in the `LiveChartsCore.SkiaSharpView.Painting`
namespace.

:::info
This article highlights the most used features. Every property is listed in the API explorer:
[SolidColorPaint]({{ website_url }}/api/{{ version }}/LiveChartsCore.SkiaSharpView.Painting.SolidColorPaint),
[LinearGradientPaint]({{ website_url }}/api/{{ version }}/LiveChartsCore.SkiaSharpView.Painting.LinearGradientPaint),
[RadialGradientPaint]({{ website_url }}/api/{{ version }}/LiveChartsCore.SkiaSharpView.Painting.RadialGradientPaint) and
[DashEffect]({{ website_url }}/api/{{ version }}/LiveChartsCore.SkiaSharpView.Painting.Effects.DashEffect).
{{~ if xaml ~}}
In XAML, create them with the `{lvc:SolidColorPaint}`, `{lvc:LinearGradientPaint}` and `{lvc:RadialGradientPaint}`
markup extensions, see [paints in XAML](#paints-in-xaml).
{{~ end ~}}
:::

## Solid color

`SolidColorPaint` paints with one color. Pass it an `SKColor`: a named color from `SKColors`,
`new SKColor(r, g, b, a)` or `SKColor.Parse("#FF0000")`. `WithAlpha` changes the transparency of a color, from `0`
(transparent) to `255` (opaque).

![image](https://raw.githubusercontent.com/beto-rodriguez/LiveCharts2/master/docs/_assets/1.6.solid.png)

```csharp
new LineSeries<int>
{
    Values = new [] { 4, 2, 8, 5, 3 },
    GeometrySize = 22,
    Fill = new SolidColorPaint(SKColors.Red), // mark
    Stroke = new SolidColorPaint(SKColors.Blue) { StrokeThickness = 6 }, // mark
    GeometryStroke = new SolidColorPaint(SKColors.GreenYellow) { StrokeThickness = 6 } // mark
}
```

## Theme, null and default paints

When a paint property is not set, the theme assigns one, see the
[themes article]({{ website_url }}/docs/{{ platform }}/{{ version }}/Overview.Themes). A paint you set is never
replaced by the theme.

`null` is a valid paint: the element is not drawn. `Fill = null` on a line series draws only the line.

`Paint.Default` gives the property back to the theme: the next time the chart updates, the theme assigns its paint
again.

## Stroke thickness

When a paint draws a line, such as the `Stroke` of a series or the `SeparatorsPaint` of an axis, `StrokeThickness`
sets the width of the line in pixels. It is `1` by default, and the constructor of `SolidColorPaint` takes it as a
second argument: `new SolidColorPaint(SKColors.Blue, 4)`. `StrokeCap` sets the shape of the ends of the line
(`Butt`, `Round` or `Square`) and `StrokeJoin` the shape of the corners (`Miter`, `Round` or `Bevel`).

## Linear gradient

`LinearGradientPaint` blends two or more colors along a line. The line goes from `StartPoint` to `EndPoint`, both in
coordinates from `0` to `1`: `(0, 0)` is the top left corner of the area the paint draws in and `(1, 1)` the bottom
right one. By default the gradient goes from left to right, from `(0, 0.5)` to `(1, 0.5)`. In this sample the
columns use a vertical gradient, from `(0.5, 0)` to `(0.5, 1)`.

{{ render_sample "design/linearGradients" }}

The gradient covers the area the paint draws in, not each shape. In a Cartesian chart the series are clipped to the
draw margin (the plot area), so the gradient spans the whole plot area and a short column shows only the colors at
the bottom. In charts that do not clip their series, such as the pie chart, the area is the whole chart.

The colors are spaced equally. To place them yourself, pass `colorPos`, one position from `0` to `1` per color.
`tileMode` sets what is drawn beyond the ends of the line: `Clamp` (the default) extends the first and last colors,
`Repeat` and `Mirror` repeat the gradient.

```csharp
Fill = new LinearGradientPaint(
    new [] { new SKColor(255, 140, 148), new SKColor(220, 237, 194) }, // the colors
    new SKPoint(0.5f, 0), // start point: middle of the top edge // mark
    new SKPoint(0.5f, 1), // end point: middle of the bottom edge // mark
    new [] { 0f, 0.8f }, // colorPos: the second color is reached at 80% // mark
    SKShaderTileMode.Clamp) // tileMode
```

`new LinearGradientPaint(startColor, endColor)` is a shortcut for a left to right gradient of two colors.

:::tip
A series sets the z-index of each of its paints, and a paint draws all its shapes at one z-index. Do not use the same
paint instance in two properties, such as `Stroke` and `GeometryStroke`: create one instance per property, as the
sample does.
:::

## Radial gradient

`RadialGradientPaint` blends the colors in circles, from the `Center` outwards. `Center` uses the same `0` to `1`
coordinates as the linear gradient and is `(0.5, 0.5)` by default. `Radius` is a fraction of the width or the height
of the area, whichever is smaller, and is `0.5` by default. `colorPos` and `tileMode` work as in the linear gradient.

{{ render_sample "design/radialGradients" }}

```csharp
Fill = new RadialGradientPaint(
    new [] { new SKColor(179, 229, 252), new SKColor(1, 87, 155) },
    new SKPoint(0.5f, 0.5f), // center // mark
    0.5f) // radius // mark
```

`new RadialGradientPaint(centerColor, outerColor)` is a shortcut for a gradient of two colors with the default center
and radius.

## Dashed lines

The `PathEffect` property of a paint changes the path of a stroke. A `DashEffect`, from the
`LiveChartsCore.SkiaSharpView.Painting.Effects` namespace, draws a dashed line: its array holds the length of a dash
and then the length of a gap, in pixels, and repeats. `new DashEffect(new float[] { 30, 20 })` draws 30 pixels and
leaves 20 empty. The optional second argument, the phase, shifts the pattern along the line. This sample also rounds
the ends of each dash with `StrokeCap`.

{{ render_sample "design/strokeDashArray" }}

The same effect draws dashed separators on an axis, see the
[axes article]({{ website_url }}/docs/{{ platform }}/{{ version }}/CartesianChart.Axes).

## Shadows and blur

The `ImageFilter` property applies a SkiaSharp image filter to everything the paint draws. `DropShadow` takes the
offset of the shadow, its blur and its color, and `Blur` blurs the shapes; both are in the
`LiveChartsCore.SkiaSharpView.Painting.ImageFilters` namespace, and `ImageFiltersMergeOperation` combines several
filters. The default theme draws the tooltip background with a drop shadow:

```csharp
TooltipBackgroundPaint = new SolidColorPaint(new SKColor(235, 235, 235, 230))
{
    // x offset, y offset, blur in x, blur in y, color
    ImageFilter = new DropShadow(2, 2, 6, 6, new SKColor(0, 0, 0, 100)) // mark
};
```

## Fonts

A paint that draws text, such as `LabelsPaint`, `DataLabelsPaint`, `TooltipTextPaint` or `LegendTextPaint`, uses
the font in its `SKTypeface` property:

```csharp
LabelsPaint = new SolidColorPaint(SKColors.Gray)
{
    SKTypeface = SKTypeface.FromFamilyName("Courier New", SKFontStyle.Bold) // mark
};
```

The text size is not part of the paint, it is a property of the element, such as `TextSize` on an axis or
`DataLabelsSize` on a series.

When `SKTypeface` is not set, the paint uses the default typeface of SkiaSharp. To change the default for every
paint, register it when the app starts, before the first chart is drawn:

```csharp
LiveCharts.Configure(config => config
    .HasTextSettings(new TextSettings // mark
    {
        DefaultTypeface = SKTypeface.FromFamilyName("Arial") // mark
    }));
```

When the font has no glyph for a character, LiveCharts asks the system for a font that has it, so text in Chinese,
Arabic or other scripts is drawn without extra setup. Set the typeface yourself to choose that font.

:::info
The `FontFamily` and `SKFontStyle` properties of the paints and the `HasGlobalSKTypeface` setting are obsolete, use
`SKTypeface` and `HasTextSettings` instead.
:::

## Paints in XAML

{{~ if wpf || winui || uno || maui ~}}
A paint property accepts a hex color, which creates a `SolidColorPaint`: `Fill="#FF0000"`. `{x:Null}` sets a paint to
`null`. For anything else, use the markup extensions:
{{~ end ~}}
{{~ if avalonia ~}}
On Avalonia a paint property does not take a hex color, use the markup extensions. `{x:Null}` sets a paint to
`null`.
{{~ end ~}}

```xml
<lvc:XamlLineSeries
    Values="{Binding Values}"
    Fill="{lvc:LinearGradientPaint Colors='#FF8C94, #DCEDC2', StartPoint='0.5, 0', EndPoint='0.5, 1'}"
    Stroke="{lvc:SolidColorPaint Color='#6495ED', StrokeWidth=4, PathEffect={lvc:Dashed Array='30, 20'}}"
    DataLabelsPaint="{lvc:SolidColorPaint Color='#323232', FontFamily='Courier New'}"/>
```

- `{lvc:SolidColorPaint}` takes a `Color`.
- `{lvc:LinearGradientPaint}` takes the `Colors` separated by commas, `StartPoint` and `EndPoint` as `'x, y'`,
  `ColorPositions` separated by commas, and `TileMode`.
- `{lvc:RadialGradientPaint}` takes `Colors`, `Center` as `'x, y'`, `Radius`, `ColorPositions` and `TileMode`.
- The three take `StrokeWidth`, `StrokeCap`, `StrokeJoin`, `StrokeMiter`, `IsAntialias` and `PathEffect`, and for
  text `FontFamily`, `FontWeight`, `FontWidth` and `FontSlant`. `TypefaceMatchesChar` picks a system font that has
  the given character, for example `TypefaceMatchesChar='汉'`.
- `{lvc:Dashed}` creates a `DashEffect` for `PathEffect`: `Array` takes the dash and gap lengths separated by commas
  (`2, 2` when it is not set) and `Phase` the shift.
{{~ end ~}}
